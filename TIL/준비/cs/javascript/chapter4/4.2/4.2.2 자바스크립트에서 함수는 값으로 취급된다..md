## 자바스크립트에서 함수는 값으로 취급된다.

1. 함수는 값으로 취급된다
	* 자바스크립트에서 함수는 일반 객체처럼 값을 가질 수 있으며, 다음과 같은 동작이 가능함.
		* 리터럴에 의해 생성될 수 있음.
		* 변수, 배열의 요소, 객체의 프로퍼티 등에 할당될 수 있음.
		* 함수의 인자로 전달될 수 있음.
		* 함수의 리턴값으로 반환될 수 있음.
		* 동적으로 프로퍼티를 생성하고 할당할 수 있음.
	* 이러한 특징 덕분에 자바스크립트에서는 함수를 `일급 객체(first class object` 로 취급함. 이는 함수가 변수나 객체, 배열 등에 할당되거나 함수의 리턴값으로 사용될 수 있음을 의미함.

2. 함수의 다양한 활용
	* 자바스크립트에서 함수는 `C` 나 `JAVA` 같은 다른 언어의 함수와 유사게 입력값을 받아 처리한 후 결과를 반환하는 구조를 가지고 있지만, 자체가 값으로 취급된다는 점에서 차이가 있음.
	* 함수는 변수나 객체, 배열 등 다양한 곳에 값으로 저장될 수 있으며, 다른 함수의 인자로 전달하거나 리턴값으로도 사용할 수 있음.

* 함수는 변수나 객체의 프로퍼티로 할당될 수 있음. 예를 들어, 다음과 같이 변수를 함수로 정의하거나, 객체의 프로퍼티로 할당할 수 있음.
```javascript
// 변수에 함수 할당
var bar = function() {return 100;};
console.log(bar); // (result) 100

// 프로퍼티에 함수할당
var obj = {};
obj.baz = function() {return 200;};
console.log(obj.baz()); // (result) 200
```

* 함수 인자로 전달
	* 함수는 다른 함수의 인자로 전달될 수 있음. 예를 들어, 함수를 다른 함수에 인자로 전달하여 해당 함수를 호출할 수 있음.
```javascript
var foo = function(func) {
	func();
};

foo(function(){
	console.log('Function can be used as the argument');
});
```
`result -> Function can be used as the argument`

* 함수 리턴값으로 활용
	* 함수는 다른 함수의 리턴값으로도 사용될 수 있음. 예를 들어, 다음과 같이 함수를 리턴하는 함수를 정의할 수 있음.
```javascript
var foo = function() {
	return function() {
		console.log('This function is the return value.');
	};
};

var bar = foo();
bar(); // (result) 'This function is the return value.'
```


* **함수는 값으로 취급된다.** : 자바스크립트에서는 함수가 일반 객체처럼 값으 취급되어 변수나 객체의 프로퍼티로 할당될 수 있으며, 함수의 인자나 리턴값으로 사용할 수 있음.
* **일급 객체** : 이러한 특징으로 인해 자바스크립트의 함수는 일급 객체로 다뤄지며, 다양한 방식으로 활용이 가능함.
* **유연성** : 함수가 값으로 취급되기 때문에 자바스크립트에서는 매우 유연한 프로그래밍이 가능함.
