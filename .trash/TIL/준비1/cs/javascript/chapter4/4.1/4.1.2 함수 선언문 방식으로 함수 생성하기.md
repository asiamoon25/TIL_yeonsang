## 함수 선언문 방식으로 함수 생성하기

1. 함수 선언문 방식
	* 함수 선언문 방식은 자바스크립트에서 함수 리터럴 형식과는 달리, **반드시 함수명이 정의되어 있어야**함.
	* C/C++ 에서 사용하는 함수 정의 방식과 유사하지만, 자바스크립트에서는 `function` 키워드를 사용하여 함수를 선언함.
2. 차이점
	* C/C++ 과는 다르게, 자바스크립트의 함수 선언문에서는 반환 타입이나 매개변수의 타입(int,char 등)을 명시하지 않음.
	* 이러한 점에서 자바스크립트는 더 유연하고, 타입을 명시하지 않는 언어서의 특징을 보임.


```javascript
// add() 함수 선언문
function add(x,y) {
	return x + y;
}

console.log(add(3,4)); // (result) 7
```
* 여기서 `add` 함수는 두 개의 인자를 받아 그 합을 반환함.
* `console.log(add(3,4));` 를 통해 `add` 함수가 호출되고 결과값이 7이 출력됨.
