## 함수 표현식 방식으로 함수 생성하기

1. 함수 표현식의 개념
	* 자바스크립트에서는 함수도 하나의 값처럼 취급되며, 이를 변수에 할당하여 사용할 수 있음. 이 방식을 **함수 표현식** 이라 부름.
	* 예를 들어, 다음과 같이 함수를 변수에 할당할 수 있음.
```javascript
var add = function(x,y) {
	return x + y;
}
```

2. 익명 함수 표현식
	* 위의 예시에서 `function(x,y)` 는 **익명 함수** 임. 함수명 없이 정의된 함수로, 변수에 할당되어 사용됨.
	* 익명 함수는 일반적으로 함수 표현식에 사용되며, 이름이 없기 때문에 그 자체로 호출할 수는 없고, 변수를 통해 접근해야 함.

3. 기명 함수 표현식
	* 함수 표현식에도 이름을 붙일 수 있으며, 이를 **기명 함수 표현식** 이라고 함. 함수 내부에서 자기 자신을 재귀적으로 호출할 때 유용함.
	* 아래 예시에서 `factorial` 이라는 이름이 함수 내부에서 사용되며, 재귀 호출을 통해 팩토리얼을 계산함.
```javascript
var factorialVar = function factorial(n) {
	if(n <= 1) {
		return 1;
	}
	return n * factorial(n-1);
}
```

4. 세미콜론 사용
	* 함수 선언문과 달리, **함수 표현식은 세미콜론(;) 으로 끝맺는 것이 권장됨**. 이는 함수 표현식이 하나의 구문(statement)으로 처리되기 때문
	* 세미콜론을 사용하지 않으면, 예기치 못한 오류가 발생할 수 있음.
```javascript
var func = function() {
	return 42;
}; // 세미콜론을 사용하여 구문을 명확하게 종료
```

5. 즉시 실행 함수 표현식(IIFE)
	* 함수 표현식을 바로 실행할 수 있는 방식으로, **즉시 실행 함수 표현식** 이 있음. 이 방식은 익명 함수로 자주 사용되며, 함수 정의와 동시에 실행됨.
	* 아래 코드에서 함수는 정의되자마자 즉시 실행됨.
```javascript
(function) {
	console.log('This function runs immediately!');
})();
```
