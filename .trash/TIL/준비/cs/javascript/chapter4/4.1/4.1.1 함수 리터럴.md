## 함수 리터럴
* 자바스크립트에서는 함수도 일반 객체처럼 값으로 취급되며, 함수 리터럴을 사용하여 함수를 생성할 수 있음.
* 함수 리터럴을 통해 함수를 정의하는 방식은 다음과 같음.
```javascript
function add(x,y) {
	return x + y;
}
```

### 함수 리터럴 구성 요소
1. function 키워드 : 자바스크립트에서 함수를 정의할 때 사용하는 키워드
2. 함수명 : 함수의 이름임. 함수의 이름은 선택 사항이지만, 주로 명명된 함수로 선언하는 경우가 많음. 선택 사항이기 때문에 이름 없이 익명 함수선언할 수 있음.
3. 매개변수 리스트 : 함수가 호출될 때 전달되는 인자(매개변수)들을 받는 부분임. 이 부분은 괄호로 둘러싸여 있으며, 여러 개의 매개변수를 사용할 수 있음.
4. 함수 몸체 : 함수가 호출될 때 실행되는 코드 부분임. 중괄호 `{}` 로 둘러싸여 있음.
