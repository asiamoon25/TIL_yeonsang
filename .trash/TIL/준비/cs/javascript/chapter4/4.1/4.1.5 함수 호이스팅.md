## 함수 호이스팅

1. 함수 호이스팅?
	* 자바스크립트에서는 함수를 생성하는 방식에 따라, 코드가 실행되기 전에 함수의 선언이 코드의 상단으로 끌어올려지는 현상이 발생할 수 있음. 이를 **함수 호이스팅(Function Hoisting)** 이라고 한다.
		* 변수가 호이스팅 되는 경우가 있는데 이에 따라서 `var` 를 사용하지 않는게 좋다. 
	* 이 현상은 함수 선언문 방식으로 함수를 정의할 때 발생하며, 함수가 정의되기 전에 호출할 수 있는 유연성을 제공함.

2. 함수 선언문과 함수 호이스팅
	* 함수 선언문으로 함수를 정의하면, 자바스크립트 엔진이 코드 실행 전에 함수 선언을 코드의 상단으로 끌어올림.
	* 아래 예시에서 보듯이 `add(2,3);` 와 같은 호출이 함수가 정의되기 전에 위치해 있어도, 함수는 정상적으로 호출이 된다.
```javascript
add(2,3); // (result) 5

function add(x,y) {
	return x + y;
}

add(3,4); // (result) 7
```

3. 함수 표현식과 함수 호이스팅
	* 함수 표현식으로 함수를 정의할 경우, 함수 호이스팅이 발생하지 않음.
	* 이로 인해, 함수가 정의되기 전에 해당 함수를 호출하면 오류가 발생함.
	* 예시에서 `var add = function(x,y){return x + y;};` 와 같은 함수 표현식을 사용하면, 함수가 정의되기 전에는 호출할 수 없음.
```javascript
add(2,3); // Uncaught TypeError

var add = function (x,y) {
	return x + y;
};

add(3,4); // (result) 7
```

4. 호이스팅의 이유
	* 함수 호이스팅은 자바스크립트의 변수 선언과 초기화 과정이 분리되어 진행되기 때문에 발생
	* 함수 선언문은 코드의 실행 컨텍스트가 생성될 때 먼저 처리 되지만, 함수 표현식은 실행 시점에서 할당되므로 그 전에 접근하면 오류가 발생함.
