## Function() 생성자 함수를 통한 함수 생성

1. Function() 생성자
	* 자바스크립트에서 `Function()` 이라는 기본 내장 생성자를 사용하여 함수를 생성할 수 있음.
	* 이 방법은 함수 선언문이나 함수 표현식과는 다른 방식으로, 직접적으로 함수를 생성할 수 있는 객체지향적 방식임.
	* 결과적으로 `Function()` 생성자 함수를 사용해도 내부적으로는 함수 객체가 생성됨.

2. 구문
	* `Function()` 생성자를 통해 함수를 생성하는 기본 구문은 다음과 같음.
```javascript
new Function(arg1,arg2,..., functionBody)
```
* arg1, arg2,... : 함수의 매개변수로 전달되는 인자들임.
* functionBody : 함수가 호출될 때 실행될 코드로, 문자열 형태로 작성됨.
```javascript
var add = new Function('x','y','return x + y;');
console.log(add(3,4)); // (result) 7
```
* `x` 와 `y` 는 함수의 매개변수 이며, `reutnr x+y;` 는 함수가 실행될 때 수행되는 코드임.

3. 주의점
	* 일반적으로 `Function()` 생성자를 사용하는 방식은 자주 사용되지 않으며, 코드의 가독성과 유지보수성을 떨어뜨릴 수 있음.
	* 이 방법은 보통 다른 사람의 코드에서 보거나, 특별한 목적을 위해 사용될 수 있음. 일반적인 개발에서는 함수 선언문이나 함수 표현식을 사용하는 것이 더 바람직함.
