## 자바스크립트에서는 함수도 객체다
* 자바스크립트에서 함수는 **함수 객체** 라고 불리며, 함수는 단순히 코드를 실행하는 것뿐만 아니라 객체처럼 프로퍼티를 가질 수 있음.
* 즉, 함수는 실행 가능한 코드인 동시에 일반 객체처럼 속성과 메서드를 가질 수 있음.

**예시 : 함수에 프로퍼티 추가하기**
* 다음은 함수 선언문을 사용하여 `add` 라는 함수를 정의하고, 이 함수에 `result` 와 `status` 라는 프로퍼티를 추가하는 예시임.
```javascript
function add(x,y) {
	return x + y;
}

// 함수에 프로퍼티 추가
add.result = add(2,3);
add.status = 'OK';

console.log(add.result); // (result) 5
console.log(add.status); // (result) 'OK'
```
* 위 코드는 `add` 함수는 일반적인 함수처럼 호출할 수 있을 뿐만 아니라, `result` 와 `status` 라는 프로퍼티도 가지게 됨.



1. 함수는 객체 : 자바스크립트에서 함수는 객체로 취급되며, 객체처럼 프로퍼티를 가질 수 있음.
2. 프로퍼티 추가 : 함수가 실행된 결과를 `result` 라는 프로퍼티에 저장하고, `status` 라는 추가적인 프로퍼티도 생성할 수 있음.
3. \[\[Code\]\] 내부 프로퍼티 : 함수 객체는 일반 객체와 달리 실행할 수 있는 코드를 나타내는 `[[CODE]]` 내부 프로퍼티도 가짐.
