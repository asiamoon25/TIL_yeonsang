# WIKI-LLM

목적 : 신입 사원을 위한 WIKI LLM 모르는 것을 질문하면 WIKI 에 있는 내용을 기반으로 LLM 이 답변을 해줌.

## 서비스
### MarkDown 처리기
Markdown 라이브러리로 markdown 을 qdrant 에 넣을 형태로 만드는 서비스


### File 처리기
파일을 찾아서 처리하는
파일 유무, 파일 리스트

### VectorDB 연동
CRUD 일반 DB 처럼 기능 구현

### File + MarkDown + Vector 데이터 처리기
모든 기능을 모아 Qdrant 에 넣는 작업이 들어가 있는 서비스
