## 웹 개발

**초급~중급**

- **할일 관리 앱** - React/Vue + Node.js로 CRUD 기능, 상태 관리, API 연동을 보여줄 수 있음
- **날씨 앱** - 외부 API 활용, 위치 기반 서비스, 반응형 디자인 구현
- **개인 블로그** - Next.js/Gatsby로 SEO 최적화, 마크다운 지원, 댓글 시스템 구현

**중급~고급**

- **실시간 채팅 앱** - WebSocket, Socket.io 활용한 실시간 통신
- **온라인 쇼핑몰** - 결제 시스템, 장바구니, 주문 관리 등 복합적 기능
- **소셜 미디어 클론** - 인증, 팔로우 시스템, 피드 알고리즘 구현

## 모바일 개발

- **가계부 앱** - 차트 라이브러리 활용, 로컬 저장소 관리
- **운동 기록 앱** - 센서 활용, 데이터 시각화
- **위치 기반 맛집 추천** - 지도 API, GPS 활용

## 백엔드/데이터

- **RESTful API 서버** - 인증, 권한 관리, 문서화 포함
- **웹 스크래퍼** - 데이터 수집, 정제, 스케줄링
- **로그 분석 시스템** - 대용량 데이터 처리, 실시간 모니터링

## 특별한 아이디어

- **개발자 도구** - 코드 포맷터, API 테스터, 정규식 검증기
- **게임** - 간단한 퍼즐 게임이나 2D 플랫폼 게임
- **자동화 도구** - 일상 업무 자동화, 봇 개발
